# Etapa 119 — Interfaz para cargar fotografías

Se implementó una interfaz web móvil en `web/index.html`, `web/styles.css` y `web/app.js`: nombre de proyecto, selección múltiple o arrastrar y soltar, validación local de 3 a 100 fotografías JPG/PNG/WebP (hasta 20 MB cada una), lista de archivos, errores accesibles, reinicio y descarga de manifiesto JSON. Los archivos no salen del dispositivo en esta etapa; el manifiesto no incluye imágenes. No se ha integrado todavía con COLMAP ni con un backend (etapa 120).

Para visualizarla localmente: abrir `web/index.html` en un navegador compatible. No se publicó ni desplegó. Pendiente: pruebas manuales y automatizadas en navegador.
