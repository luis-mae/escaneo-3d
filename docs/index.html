Escaneo 3D

Demostración verificable de visualización y exportación de una pieza de ejemplo. NO reconstruye fotografías.

1. Modelo de ejemplo

Una pieza prismática con una perforación central, generada geométricamente en tu navegador.

Modelo de prueba listo.

2. Preparar fotografías reales

Elegí entre 10 y 30 fotografías del mismo objeto, tomadas desde diferentes ángulos. Podés comprobar aquí la selección antes de disponer del servidor de reconstrucción.

Todavía no seleccionaste fotografías.

Estado: la selección funciona en este navegador. El procesamiento real con COLMAP necesita un servidor; esta demostración no envía ni reconstruye fotografías.

3. Lo que falta para un escaneo real

Capturar fotografías → enviarlas a la API local → ejecutar COLMAP → generar malla → revisar y exportar. Este archivo permite comprobar el visor y la exportación sin afirmar que esas etapas ya están validadas.
